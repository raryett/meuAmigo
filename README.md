Meu Amigo
Este é um projeto simples desenvolvido em Java, com foco em exemplos básicos de interação e manipulação de dados. Ele serve como uma base para demonstrar funcionalidades essenciais da linguagem e pode ser utilizado como ponto de partida para estudos ou protótipos.

🚀 Começando
Para clonar e executar este projeto em sua máquina local, siga os passos abaixo:

Pré-requisitos
Certifique-se de ter os seguintes softwares instalados:

Java Development Kit (JDK): Versão 17 ou superior. Você pode baixar em Oracle JDK ou Open JDK.

Git: Para clonar o repositório. Você pode baixar em git-scm.com.

Gradle: (Opcional, mas recomendado se for usar a estrutura de build) Para gerenciar as dependências e construir o projeto. Pode ser instalado via Gradle.

Instalação e Execução
Clone o repositório:

Bash

git clone https://github.com/raryett/meuAmigo.git
Navegue até o diretório do projeto:

Bash

cd meuAmigo
Compile e execute o projeto:

Se você estiver usando o Gradle:

Bash

gradle run
Ou, se preferir compilar e executar manualmente:

Bash

javac src/Main.java src/Funcoes.java # Ajuste conforme a estrutura de pastas dos seus arquivos .java
java Main
🛠️ Tecnologias Utilizadas
Java: Linguagem de programação principal.

Gradle: Sistema de automação de build (gerenciamento de dependências e compilação).
